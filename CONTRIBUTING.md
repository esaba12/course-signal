# Contributing

## Team rule

Never push directly to `main`. Create a small branch, open a PR, and leave it for human review and merge.

## Good tasks for non-technical partners

- Test a page without explanation and list confusing labels.
- Check that every slide/demo statement has source evidence.
- Rewrite a tooltip in plain language without changing the underlying metric.
- Rehearse judge questions using `docs/HACKATHON-RUNBOOK.md`.

## Pull request description

State what changed, why a user cares, how it was checked, data/privacy implications, and what did not change. Do not make capacity, waitlist, or automated-decision claims unless the product scope has been explicitly changed.
