# Course Signal — Product Story

Course Signal is a configurable planning signal for registrars and course planners. It compares an institution’s own course-term history and produces a transparent, backtested estimate for a comparable future term.

The product does not assume that every institution measures the same thing. Each deployment names its metric, source, academic terms, provenance, and optional current-status capabilities. UIUC is only the first public-data adapter.

The output is decision support: a prompt to investigate course context with a human, not an automated recommendation to add, cut, staff, or schedule a section.
