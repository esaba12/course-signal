# UIUC Demo Adapter

The hosted demo uses UIUC because its historical GPA dataset is public, easy to retrieve, and useful for demonstrating the workflow without requesting institutional data.

UIUC is not the product scope. Its adapter supplies one institution name, one measurement definition (completed-grade headcount), one public source, and an optional Course Explorer status connector. A future institution must provide an authorized historical extract and its own measurement definition before configuration.
