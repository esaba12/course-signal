# UIUC Demo Adapter

The hosted demo uses UIUC because its historical GPA dataset is public, easy to retrieve, and useful for demonstrating the workflow without requesting institutional data.

UIUC is not the product scope. Its adapter supplies one institution name, one measurement definition (completed-grade headcount), one public source, and an optional Course Explorer status connector. A new institution should provide its own authorized historical extract and definitions through [institution onboarding](INSTITUTION-ONBOARDING.md).
